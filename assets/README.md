# Artwork used in generated covers

Vectors that `scripts/make-figure.mjs --mark` sets beside a figure. Each one is somebody else's,
so an article using it credits the owner and carries the page it came from in `cover.source`.

- `litacka-card.svg` — the PID Lítačka travel card, from the PID Lítačka e-shop:
  `https://prod-pidlitacka-eshop-strapi.k8s-prod.oict.cz/uploads/litacka_card_6ce0691e6a.svg`
  Used only where the card is the subject — what a pass costs, what the app does — never as
  decoration on an unrelated transport story.
