Prague Insider je statický web. Nemá uživatelské účty, diskuse, databázi newsletteru ani reklamní síť.

## Co sbíráme

Nic. Web nenastavuje cookies, nespouští analytické skripty a nevkládá cizí sledovací kódy, sociální
widgety ani písma. Typografie se načítá z této domény.

## Co vidí hosting

Web běží na GitHub Pages. Jako každý webový server i GitHub zaznamenává požadavky — včetně vaší
IP adresy — aby mohl stránky doručit a bránit se zneužití. Toto zpracování provádí GitHub podle
[svého prohlášení o ochraně soukromí](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
K těmto logům nemáme přístup.

## Stránka s mapou

[Mapa](/mapa/) načítá podkladové dlaždice od služby CARTO, čímž se CARTO nutně dozví vaši IP adresu.
Žádná jiná stránka nenačítá nic z cizí domény. Pokud si nepřejete s CARTO komunikovat vůbec, prostě
mapu neotvírejte — všechny články fungují i bez ní.

## Odkazy ven

Každý článek odkazuje na původní zdroje na jiných webech. Ty mají vlastní pravidla ochrany soukromí,
která neovlivňujeme a za která neručíme.

## E-mail

Pokud nám napíšete, zprávu držíme po dobu nezbytnou k jejímu vyřízení. Nikoho nezařazujeme do
žádného seznamu.
